# Bittu Prasad Mandal — Portfolio

A professional portfolio website showcasing my projects, skills, education, and work experience.

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox, Animations
- **JavaScript** — Smooth scroll, mobile menu, intersection observer
- **Font Awesome** — Icons
- **Google Fonts** — Inter & JetBrains Mono

## Sections

- Hero — Introduction with animated profile ring
- About — Summary and key stats
- Education — Timeline with GPA badges
- Experience — Work history with descriptions
- Projects — 5 featured projects with tags
- Skills — Categorized technology stack
- Contact — Form and social links

## Live Site

View the live portfolio at: [https://ronak904.github.io/portfolio](https://ronak904.github.io/portfolio)

## Local Development

```bash
git clone https://github.com/ronak904/portfolio.git
```
