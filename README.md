## About

A production-grade personal portfolio for **Bittu Prasad Mandal** — a web developer (JavaScript · Java · HTML · CSS). The site is fully animated, responsive, theme-aware, and reflects only **real, verifiable work**: real education, real experience, and real public projects.

## Highlights

- **Futuristic, engineer-grade visuals** — animated particle network, circuit-board background, floating code glyphs, and a live developer terminal in the hero.
- **Animated profile summary** — key highlights typed out live in a terminal window.
- **Tech Stack as an animated radar graph** — skills visualize as an interactive radar chart that grows into view.
- **Typewriter hero effect** — rotating roles typed out live.
- **Light & dark mode** — theme toggle in the navigation, respects system preference, persisted across visits.
- **Completely responsive** — off-canvas navigation on mobile, adaptive grids, no horizontal scroll.

## Sections

| Section | Content |
| --- | --- |
| Hero | Animated typewriter roles, developer terminal, engineering-focused intro |
| About | Professional profile summary + at-a-glance stats |
| Education | Verified academic timeline (Class X → +2 Science → BTech CSE) |
| Experience | Real roles — The Developers Area, Subisu Pvt. Ltd. |
| Selected Work | Five featured public repositories with links |
| Skills | Animated radar chart + categorized technology stack |
| Contact | Branded links to GitHub, LinkedIn, Email |

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, Grid, Flexbox, keyframe animations
- **Vanilla JavaScript** — particle network, radar chart, typewriter, theme toggle, scroll-reveal
- **Font Awesome** — icons
- **Google Fonts** — Inter, JetBrains Mono, Orbitron
- **GitHub Pages** — free hosting with automatic deploys

## Local Development

```bash
git clone https://github.com/ronak904/portfolio.git
cd portfolio
open index.html
```

No build step required — this is a single self-contained HTML file.
